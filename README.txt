BUJJIKUTTY BIRTHDAY WEBSITE

1. Put your real photos inside the "photos" folder.
2. Replace photo1.jpg through photo5.jpg. Keep the exact filenames.
3. Open index.html in a browser to preview.
4. To publish free with GitHub Pages:
   - Create a new GitHub repository.
   - Upload index.html, style.css, script.js, and photos folder.
   - Settings > Pages > Deploy from branch > main / root.
   - Open the generated Pages link.

The final "Play our song" button opens the YouTube link you provided.
